\# AutoLoc



Plateforme de gestion de location de véhicules multi-agences.



\## Objectif

Permettre la gestion des véhicules, des clients et des réservations

dans plusieurs agences de location.



\## Acteurs

\- \*\*Client\*\* : consulte les véhicules et réserve.

\- \*\*Agent d'agence\*\* : gère les locations au quotidien.

\- \*\*Responsable d'agence\*\* : supervise son agence.

\- \*\*Administrateur\*\* : administre la plateforme.



\## Environnement

Java 17, Spring Boot, Maven, MySQL (WAMP), IntelliJ IDEA, Postman, Git.
